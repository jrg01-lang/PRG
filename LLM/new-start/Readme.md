# Actividad: Página de Noticias Gamer

## 📌 Descripción
En esta actividad vas a trabajar con un archivo HTML y CSS que simula un portal de **noticias de videojuegos**.  
El objetivo es **comprender la estructura del documento**, identificar las secciones principales (cabecera, menú, contenido, aside y pie de página) y practicar la personalización de estilos con CSS.  

La web incluye:
- Un **header** con logotipo, menú de navegación y buscador.
- Un **main** con artículos de noticias y un **aside** con buscador y publicidad.
- Un **footer** con información del sitio.
- Estilos personalizados con **variables CSS**, tipografía de **Google Fonts** y **iconos de FontAwesome**.
- Diseño **responsivo** mediante *media queries*.

---

## 🛠️ Requerimientos
1. Analiza el fichero HTML y responde:
   - ¿Qué etiquetas estructuran la página?  
   - ¿Cómo se implementa el diseño responsivo?
2. Añade al menos **una nueva noticia** en la sección `<section>` con la misma estructura de `<article>`.
3. Cambia el color principal (`--color-accent`) en las variables CSS y observa cómo afecta al diseño.
4. Inserta un nuevo elemento en el menú de navegación.
5. Sustituye las imágenes por otras relacionadas con videojuegos usando enlaces externos.
6. Comprueba el resultado en **pantallas grandes y pequeñas** (responsividad).
